# NEON RUSH — Night Drive 3D Upgrade

This version replaces the box-like car with a tapered procedural sports-car body, shaped cabin windows, rims, headlamps, rear lights, underglow and headlight beams. Buildings have varied heights, facade window grids, ledges, rooftop structures and neon accents. Street lamps have curved arms and local lights.

## Install on GitHub from Android
1. Extract the ZIP.
2. Open your GitHub repository.
3. Open `src/main.js` and choose Edit (pencil / `...` menu).
4. Replace the complete file contents with the `src/main.js` in this package, then Commit changes.
5. If you have not uploaded the entry files, upload `index.html` and `style.css` to the repository root too.
6. GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
7. Wait for the Pages deployment and open the HTTPS URL on your phone.

Three.js loads from a CDN, so internet access is required. This is still a procedural arcade prototype, not a photorealistic game with downloaded car assets. AdsGram requires your own publisher Block ID; replace `YOUR_ADSGRAM_BLOCK_ID` in `src/main.js` after creating a block in the dashboard.
